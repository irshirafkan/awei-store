# 🎧 AWEIstore – Audio Equipment E-commerce

AWEIstore is a front-end e-commerce project focused on selling audio products such as AirPods, headphones, and headsets.

This project was built during my JavaScript learning phase, when I had an intermediate level of JS knowledge and was actively improving my skills through real-world practice and problem-solving.

---

## 🎯 Project Purpose

The main goal of this project was to:

- Strengthen my JavaScript fundamentals through a real project  
- Simulate a real e-commerce experience without a backend  
- Practice working with structured data using JSON  
- Improve UI development and responsive design skills  
- Learn how to organize code in a more scalable way  

---

## 🧠 Architecture Approach

Even though this is a front-end only project, I tried to simulate a more dynamic and structured system:

- Used a **JSON file as a mock database** for products  
- Products are dynamically rendered from data (not hardcoded in HTML)  
- Followed a **component-like approach** for product cards to avoid repetition  
- Tried to keep the structure modular and reusable  

This helped me understand how real-world front-end applications manage and render data.

---

## ✨ Features

- 🛍️ Dynamic product listing from JSON data  
- ❤️ Wishlist (favorites) functionality  
- 🛒 Shopping cart system
